# EmoteCall

EmoteCall es una aplicación innovadora diseñada para entrevistas con monitorización de expresiones faciales en tiempo real. Utiliza tecnologías de análisis de emociones para brindar retroalimentación visual durante videollamadas, ayudando a los usuarios a mejorar su comunicación no verbal.

### Tecnologías clave

- **Frontend**: React.js, Material-UI, Emotion (estilización)
- **Backend**: FastAPI (API REST en Python)
- **Herramientas de desarrollo**: Vite, TypeScript, ESLint

El proyecto está diseñado para ser escalable y fácil de mantener, con un frontend modular y un backend eficiente.

#### Características destacadas

- Reconocimiento de emociones mediante IA
- Integración con videollamadas
- Panel de métricas en tiempo real
- Diseño responsive y accesible

Para empezar, revisa los archivos de configuración del frontend (`frontend/package.json`) y backend (`backend/pyproject.toml`).
